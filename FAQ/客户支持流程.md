# 2 客户支持流程

由于Android系统功能和代码量庞大，我们FAE支持工作比较复杂，需要流程化和规范化来进行相关支持和沟通。

## 2.1 客户评估和商务流程

1. 新客户导入以后需要FAE/销售/产品经理/智能模块接口人对接，评估客户项目需求可行性，明确调试功能块和任务分工。

2. 硬件封装（原理图、PCB在客户确认立项前与硬件HD文档同步发给客户），便于客户的开发及后续审核工作量。

3. 评估通过以后，需要立项，需要签署NDA。

4. FAE把客户硬件原理图审核提到JIRA（提给硬件李兵）。

5. FAE把软件需求提到JIRA。

注意：必填JIRA（原则上不提JIRA不处理客户问题）。可以同时使用微信群/邮件等其他工具辅助客户沟通交流具体问题。

# 3 客户需求 Bug 管理

## 3.1 使用JIRA管理客户需求和Bug

开发调试客户需求需要提到JIRA上，如果没有FAE提JIRA单。研发无法及时完整跟进客户问题状态。每个客户问题都需要提一个JIRA。提给研发接口人。

## 3.2 JIRA提单规则

例如客户有5个需求，要提5个JIRA。客户需求每增加一个，就需要提一个新的JIRA。如果客户提出的单个需求需要多人处理，要拆分成多个JIRA（具体如何拆分找接口人袁明洋沟通）。
